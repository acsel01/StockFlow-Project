# StockFlow

StockFlow es una aplicación web orientada a pequeños comercios que integra
punto de venta, control de inventario, caja y consulta pública de productos.

## Estado del proyecto

Proyecto Anual 2026 — Programación.

Actualmente el proyecto se encuentra en etapa de investigación,
definición de alcance y planificación.

## Objetivo

Facilitar la gestión diaria de pequeños comercios y aprovechar la
información del inventario para permitir que potenciales clientes
consulten productos y disponibilidad antes de acercarse al negocio.
